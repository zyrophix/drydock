# Support

- **Bug reports and feature requests:** open an issue (use the templates).
- **Questions and usage help:** open a discussion, not an issue.
- **Security vulnerabilities:** never public — see [SECURITY.md](SECURITY.md).

No guaranteed response time; this is maintainer-spare-time software. Well-formed reports (version, platform, repro) get answered first.
